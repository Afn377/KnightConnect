# KnightConnect — Request Form Requirements

## Overview
This document defines the proposed minimum fields and functionality for students requesting to join opportunities or hackathon teams through KnightConnect.

## Required Fields
- **Student ID:** Automatically obtained from the logged-in user's account.
- **Opportunity ID:** Identifies which opportunity the student wants to join.
- **Message:** A short explanation of why the student wants to join.

## Optional Fields
- **Skills:** Relevant skills the student wants to highlight.
- **Availability:** When the student is available to collaborate.

## Request Workflow
1. Student browses available opportunities.
2. Student selects an opportunity.
3. Student clicks "Request to Join."
4. Student completes the request form.
5. System validates the required fields.
6. Student submits the request.
7. Request status is set to "Pending."
8. Opportunity owner reviews the request.
9. Owner accepts or declines the request.

## Request Statuses
- **Pending:** Waiting for review.
- **Accepted:** Request approved.
- **Declined:** Request rejected.
